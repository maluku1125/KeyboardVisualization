# Key Visualizer — 實況用即時按鍵可視化

繁體中文 | [English](README.en.md)

按下的按鍵(含滑鼠鍵)會以圓角方形沿時間軸滑動,長按會拉長,並顯示 KPS 統計。使用全域監聽,遊戲視窗在前景時也能捕捉輸入。

## 快捷鍵

| 鍵 | 功能 |
|---|---|
| F1 | 切換滑動方向(右→左 / 左→右) |
| F2 | 重置統計 |
| F3 | 開啟/關閉設定頁面 |
| F4 | 開始/停止錄製(錄製中顯示紅點) |
| F8 | 點擊穿透開/關(全域,透明模式) |
| ESC | 關閉設定頁面 / 離開 |

## 設定頁面 (F3)

分三個分頁,改動即時生效並自動存回 `config.json`:

- **一般**:語言(中/英)、顯示模式(時間軸/推擠列)、推擠列格數與淡出秒數、圖示上顯示鍵名、軌道數、背景透明度、顯示按壓長度(關閉後每次按壓顯示固定正方形)、滑鼠偵測、點擊穿透、鎖定按鍵(只在設定開啟時新增陌生按鍵)、滑動方向、滑動速度、錄製功能開關(關閉後 F4 無作用、也不會自動錄製)、自動錄製、視窗尺寸、總是在最頂層、現在線、統計列、綠幕模式。
- **按鍵**:以 QWERTY 實體排列列出整張鍵盤與滑鼠鍵(滾輪捲動),每個按鍵可以「圖片」選自訂圖示、✕ 清除圖示、「停用」不顯示該鍵、右側 − / + 指定固定軌道(「自動」表示動態分配)。
- **Preset**:把目前的按鍵設定(圖片、固定軌道、停用、標籤、顏色、軌道數)存成多組,一鍵「套用」切換,適合不同遊戲用不同 icon 組。存於 `presets/`。

## 錄製 (F4) 與譜面檢視器

- 按 F4 開始/停止錄製,或在設定開「自動錄製」(啟動即錄,關閉程式自動存檔)。紀錄存在 `recordings/rec_日期時間.json`,包含所有按鍵事件、軌道、顏色、標籤與內嵌的按鍵圖片,單檔即可分享。
- 紀錄檔格式 **v2**:圖片以內容雜湊去重(重複使用的技能圖只存一份,檔案大幅縮小)、附帶 metadata(遊戲/職業/伺服器/角色/備註/preset/輸入模式)與**簽章**。檢視器會顯示「✓ 已驗證」(由程式直接產生)或「⚠ 內容已變更」(JSON 被手動編輯過)。舊的 v1 紀錄檔仍可正常開啟,只會標示為「未驗證」。
- metadata 可在 `config.json` 的 `meta_game` / `meta_job` / `meta_server` / `meta_character` / `meta_note` 欄位填寫。
- **檢視器**:<https://maluku1125.github.io/KeyboardVisualization/> (即 `index.html`,純靜態網頁)。拖放或選擇紀錄檔即顯示全程譜面,支援滾輪縮放、拖曳平移、點擊定位、播放(空白鍵,0.5×~4×)、KPS 曲線與統計。紀錄檔只在瀏覽器本機解析,不會上傳。

## 點擊穿透 (F8)

透明模式下按 F8,滑鼠會直接穿過視窗點到底下的遊戲;再按一次 F8 恢復。設定頁開啟時會暫時解除穿透以便操作。

## 背景透明(僅 Windows)

「背景透明度」只影響背景,按鍵方塊保持不透明。調到 100% 以下會切換成無邊框、置頂的覆蓋視窗,可直接疊在遊戲畫面上,用滑鼠左鍵拖曳移動;0% 時背景完全穿透只剩按鍵。要調整設定按 F3(視窗需在焦點,可先點一下按鍵方塊或工作列圖示)。視窗尺寸可在設定中調整。

## OBS 使用

視窗擷取即可;要去背可開「綠幕模式」再加色度鍵濾鏡,或直接用背景透明模式疊在畫面上。

綠幕顏色可在設定中切換(綠 / 藍 / 洋紅 / 青 / 自訂),**如果你的按鍵圖含有綠色會被一起濾掉,改選洋紅或藍色即可**。選「自訂…」會開啟系統選色器。

## 效能與輸入延遲

預設開啟「**低延遲模式**」:用輪詢方式讀取按鍵狀態,完全不掛系統 hook、不在遊戲的輸入路徑上,**不會增加任何按鍵延遲**;代價是短於一幀(60fps 約 16ms)的極短按壓可能漏抓。關閉此模式則改用全域 hook,時序最精準(適合錄製譜面),但按鍵事件會先經過本程式再送到遊戲,重載時可能增加數毫秒延遲。「畫面更新率上限」可調 30~240 FPS,調低可減少 CPU 佔用。

## 防毒軟體誤判

本程式會監聽全域按鍵,特徵與鍵盤側錄程式相似,**部分防毒軟體會誤判**。常見症狀是「開啟後約 30 秒被強制關閉」或提示「無法存取」——那是防毒把程式解壓在暫存資料夾的檔案刪掉了。

解法(擇一):

1. **改用資料夾版**(`KeyVisualizer.zip`,解壓後執行裡面的 `KeyVisualizer.exe`)。資料夾版不解壓到暫存目錄,誤判機率大幅降低。
2. 在防毒軟體加入例外:Windows 安全性 → 病毒與威脅防護 → 管理設定 → 排除項目,把程式資料夾加進去。可先到「保護歷程記錄」確認是否真的被隔離。
3. 直接用 Python 執行 `key_visualizer.py`,不打包成 exe。

單檔版(`KeyVisualizer_single.exe`)方便攜帶但誤判率最高。徹底解決需要購買程式碼簽章憑證(約每年數百美元)。

### 兩種版本怎麼選

| 版本 | 適合 | 缺點 |
|---|---|---|
| `KeyVisualizer.zip`(資料夾版) | **推薦**,大多數人 | 要先解壓縮,檔案較多 |
| `KeyVisualizer_single.exe`(單檔版) | 想隨身帶著跑 | 較容易被防毒誤判、啟動較慢 |

`build_exe.bat` 會一次產生這兩個版本,直接把兩個檔案都放上發佈頁讓使用者自選。

## 注意

- 部分防作弊遊戲可能阻擋全域鍵盤監聽;獨占全螢幕的遊戲蓋不住,請改用無邊框視窗化。
- 手動改 `config.json` 需重新啟動程式(設定頁面內的改動即時生效)。
